## Current production snapshot

Verified September 12, 2026 on the deployed branch stack: 23 production sources are healthy, with 2,880 canonical projects, 1,931 projects mapped using defensible geometry, and 949 projects intentionally left location-pending rather than assigned fake pins. The regression set for Scotts Valley casino, SR-37 Sears Point–Mare Island, Napa Pipe, One Lake / Canon Station, and Dutch Bros Suisun is fully map-ready.

## Environment limits observed September 13, 2026

Verification for this pass ran from a remote session whose egress policy could not
reach every jurisdiction host. `www.ci.vacaville.ca.gov`, `www.yountville.gov` and
`www.ci.calistoga.ca.us` were refused at CONNECT by the egress gateway, and
`www.riovistacity.com` returned 403. That is an environment limit, not evidence about
those sites, and it is the reason Vacaville's own city portal is not yet ingested
despite being a P0 target. Vacaville's eScribe meeting portal is reachable and remains
the next route in. Sources whose live behaviour could not be observed from here were
not promoted; a collector that cannot be proven to work is not production.

## Promotion rule

A smoke config is not promoted into `config/sources/` until the tenant passes its canary and returns expected live records. Adapter code can be production-ready while a tenant configuration remains unverified.
