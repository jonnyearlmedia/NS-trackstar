## What the environment was actually costing

Every "blocked" entry above that moved today moved because the session ran on the
operator's own machine rather than in a remote container, and none of them moved
because of new code. California ABC answered normally. The 511 token was in the
Keychain the whole time. Accela needed two headers, not a browser. PlanetBids named
its API host in a config file it serves to every visitor. Before recording a source as
blocked, it is worth asking which of the two things is being described: the source, or
where the request came from.

not promoted; a collector that cannot be proven to work is not production.

## Promotion rule

A smoke config is not promoted into `config/sources/` until the tenant passes its canary and returns expected live records. Adapter code can be production-ready while a tenant configuration remains unverified.
